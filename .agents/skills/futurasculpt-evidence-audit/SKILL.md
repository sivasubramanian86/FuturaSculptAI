# FuturaSculptAI Evidence Audit Skill

## Purpose
Enforces the Zero-Fabrication Contract. Verifies that every external claim generated by agents or presented in the UI traces back to a cryptographically validated `evidence_id` in the Evidence Ledger.

## Triggers
- When new multimodal evidence ingestion pipelines are added or modified.
- Before publishing scenario simulations, role transition proposals, or investor dossiers.

## Audit Procedure
1. **EvidenceEnvelope Schema Validation:**
   - Verify every evidence record contains `evidence_id`, `tenant_id`, `sha256_hash`, `source_uri`, `content`, `provenance`, and `acl`.
2. **Claim-to-Evidence Entailment Check:**
   - Scan generated scenario outputs and Opportunity Forge blueprints to confirm that 100% of factual assertions include citation markers referencing active evidence IDs.
3. **Freshness & Provenance Verification:**
   - Verify that evidence records do not exceed their `freshness_horizon_days` without explicit staleness warnings.

## Verification Script (PowerShell)
```powershell
# Assert all sample evidence files have matching sha256 checksums
Get-ChildItem -Path "data/sample_evidence" -Recurse -File | ForEach-Object {
    $hash = (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower()
    Write-Output "$($_.Name) -> $hash"
}
```

## Expected Output
Audit scorecard showing:
- Evidence coverage percentage (must be >= 95%).
- Unbacked claims or dangling citations (must be 0).
